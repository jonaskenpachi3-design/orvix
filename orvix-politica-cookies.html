1. Resumo Rápido

🎯 Em 30 segundos

  • Cookies HTTP tradicionais: NÃO usamos. Nenhum cookie de sessão, tracking ou analytics.
  • localStorage / sessionStorage: Usamos apenas para fins essenciais (autenticação JWT, preferência de tema).
  • Service Worker (PWA): Cache de assets estáticos (HTML, CSS, JS, imagens) para funcionar offline.
  • Terceiros (Google Analytics, Meta Pixel, etc.): ZERO. Não há tracking cross-site.
  • Banner de consentimento: Simples, apenas para essenciais (LGPD art. 7º, I). Você pode recusar — o app funciona sem localStorage (login expira ao fechar aba).

Para fins de LGPD e ePrivacy, localStorage/sessionStorage são tratados como cookies quando armazenam identificadores ou preferências do usuário.

5. Consentimento e Controle

5.1 Banner de Consentimento

Ao acessar o Orvix pela primeira vez (ou após limpar dados), você verá um banner simples:

Usamos armazenamento local essencial (autenticação, tema) e cache PWA para funcionar offline. Saiba mais.

Opções:

  • "Aceitar essenciais" — salva orvix_consent=essential no localStorage, banner some. App funciona 100%.
  • "Configurar" — abre modal para gerenciar individualmente (futuro). Hoje redireciona para esta política.
  • Fechar (X) / Ignorar — banner reaparece na próxima visita. Sem consentimento salvo, o app ainda funciona (token vai para sessionStorage, tema usa prefers-color-scheme).

5.2 Como Gerenciar / Remover

Efeito de limpar tudo: Você será deslogado (token removido), tema volta ao padrão do sistema, cache PWA limpo — próximo acesso recarrega assets do servidor. Seus dados financeiros não são afetados (estão no servidor PostgreSQL).

6.2 O que NÃO é compartilhado com terceiros

  • Tokens JWT, credenciais, senhas (bcrypt)
  • Transações, saldos, extratos, categorias, metas, orçamentos
  • Dados de parcelamentos, insights financeiros
  • Endereço IP (logs de acesso ficam no Render, não repassados)

Provedores de IA recebem apenas o texto da sua pergunta e o retorno das function calls (ex: lista de transações filtradas) — processamento ocorre no servidor Orvix, resultado via API.

8. Seus Direitos (LGPD Art. 18)

Sobre cookies/storage, você pode:

  • Confirmar se usamos cookies/storage (sim, essenciais + funcionais);
  • Acessar quais chaves armazenamos (DevTools → Application → Local Storage / Session Storage);
  • Corrigir preferências (trocar tema no app);
  • Eliminar todos os dados locais (limpar dados do site no navegador);
  • Opor-se ao uso de funcionais (desativar PWA nas configurações do navegador);
  • Portabilidade — não aplicável (dados locais não são "seus dados financeiros");
  • Revogar consentimento a qualquer momento (limpar dados do site).

⚡ Exercício prático

Para revogar consentimento de essenciais: limpe dados do site do Orvix no navegador. Você será deslogado. Para voltar a usar, faça login novamente (novo consentimento implícito ao logar).

9. Alterações nesta Política

  • Mudanças materiais: aviso de 30 dias via e-mail + banner no app;
  • Versão anterior arquivada e disponível mediante solicitação;
  • Continuar usando após vigência = aceitação.
